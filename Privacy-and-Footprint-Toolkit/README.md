# Privacy and Footprint Toolkit

A browser-based privacy awareness toolkit featuring a platform privacy audit, post risk scanner, password lab, digital footprint tracker, and scam-awareness learning section.

## Run locally

Open `index.html` in a modern web browser. Progress is stored in the browser using `localStorage`.

## Deploy with GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. Because this project is inside a subfolder, open the project at:

`https://joshuajaysoncse2024.github.io/PROJECTS/Privacy-and-Footprint-Toolkit/`

If Pages is not enabled for the repository, enable it first. The repository must be public for free GitHub Pages on GitHub Free.

## Privacy note

This is a front-end demonstration, not secure account authentication. Do not enter real passwords or sensitive personal information. The password breach check sends only the first five characters of a password hash to Have I Been Pwned.
